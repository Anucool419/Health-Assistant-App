# Health-Assistant-App
# Description
The **Health Assistant App** is a Streamlit-based application designed to help users monitor their health by providing tools for tracking metrics and accessing insights.
## Features
- Tools to assess daily health metrics.
- Multimedia support (videos and images).
- Short messages that provide comments on the sleep pattern, water intake and exercise routine.
## Installation
To set up the project on your local machine, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Anucool419/Health-Assistant-App.git

2. Go to Project File
  ```bash
   cd Health-Assistant-App
```
3. Setup virtual environment
  ```bash
   python -m venv venv
   source venv/bin/activate  # For Linux/Mac
   venv\Scripts\activate     # For Windows
```
4. Install necessary requirements
  ```bash
   pip install -r requirements.txt
```
5.Run the application
  ```bash
   streamlit run app.py
```

##   Usage
1.  Open your browser and go to `http://localhost:8501
2.  Input your health data and get instant insights.
